01 / My approach

Build to understand, not just to demonstrate.

I enjoy building applications that connect the pieces of software into a useful experience: core logic, models, data, tools, error handling, and an interface that makes the result understandable.

A major interest is agentic AI—systems that can use language models alongside tools, state, retrieval, and structured workflows. Projects such as PARALLAX, AURA, and IGNIX reflect my interest in moving beyond a basic chat interface toward software that can assist with real tasks.

I also explore different types of applications, including multilingual public-information assistance, decision-support workflows, research tools, and AI-assisted games. I aim to choose architecture based on the problem instead of adding complexity just to make a project look advanced.

I'm continuing to strengthen my engineering foundations through implementation, debugging, testing, and learning how to make software more reliable and maintainable.

End-to-end thinking

Connect the user experience to the underlying application logic, data, and integrations.

Safer automation

Think carefully about permissions and confirmation when tools can change files or the environment.

Proportional architecture

Use frameworks, abstractions, and orchestration when they solve a real problem.

Behavior over appearance

Check what the software actually does, including failure cases—not only what the interface promises.

03 / Engineering interests

How an agentic feature fits together.

A simplified architecture pattern I explore in agent projects. Real applications vary, and a straightforward task does not always need every layer.

LAYER 01

Input & context

Understand the request, relevant context, and constraints.

LAYER 02

Model integration

Connect a provider and shape the model's task.

LAYER 03

Orchestration

Coordinate steps, state, routing, and recovery.

LAYER 04

Tools & data

Work with retrieval, APIs, files, and other capabilities.

LAYER 05

Validation

Check permissions, verify outputs, and report results.
